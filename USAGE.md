# Publish and play

Sign in at Netlify, open https://app.netlify.com/drop, and drop the complete `netlify-ready-game.zip`. Netlify builds the project and deploys the multiplayer Function automatically. If asked for a folder, extract the ZIP and drop the folder containing `netlify.toml`.

Open the resulting site, create a room, and share the site address and room code with 2–8 players. Each player uses a separate device or fresh browser tab. Choose **3 rounds · Quick game** for a short test, or keep the five-round default.

No terminal, GitHub, API keys, environment settings or database setup are needed. Upload the complete project, including `netlify/`, rather than only the `dist` folder.
